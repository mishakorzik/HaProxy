# HaProxy
A plugin for Minecraft serve to make support HaProxy Protocol v1 and v2. 

## Compile
```bash
git clone https://github.com/mishakorzik/HaProxy
cd HaProxy
mvn clean package
```

## Notice
This plugin is experimental (not fully tested yet but it works fine).
Only for a Paper or Paper-like servers

I made this plugin for my Minecraft proxy in C
